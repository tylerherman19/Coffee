# Reference research - Coffee Prices redesign (Sept 2026)

Every value below was sampled from the live site named, not invented.
Direction brief: "independent city guide x beautifully designed consumer
utility x editorial data product"; not a coffee-roaster site, not a SaaS
dashboard, not brown-on-beige coffee cliches.

## 1. Colectivo Coffee (colectivocoffee.com) - Tyler's named "cozy" reference
- Warm paper backgrounds sampled: #fffce6, #fffdeb; ink: #3A3A3A, #1d1f27.
- Take: warmth comes from paper + ink + whitespace, NOT from brown-on-beige
  theme-parking. Restraint: near-white warm paper, single dark ink, no
  decorative coffee imagery anywhere.
- Reject: it is a roaster marketing site; the brief explicitly says this
  product is not that.

## 2. The Infatuation (theinfatuation.com) - city-guide editorial
- Type: Klim "National 2" family (grotesque) used for everything, condensed
  cuts for headlines; ink #181818; white surfaces; single blue accent
  #0066f1; one warm highlight #ffe34c used sparingly.
- Take: directory rows that scan like a restaurant guide; one accent only;
  confidence through type weight + tracking, not boxes.
- Reject: their blue. Our accent stays our own persimmon.

## 3. Transit (transitapp.com) - transit utility
- Inter Display; blue #09f; near-white #f3fff8; dense, tabular, glanceable.
- Take: proximity data (times, distances) set in tabular numerals at high
  density with zero decoration. Distance/price figures are the UI.
- Reject: startup-blue palette and app-store marketing page energy.

## 4. Citymapper (citymapper.com) - transit/city data
- Neutral #F6F6F6 surfaces, ink #4A4A4A, single green #37AB2F.
- Take: a map product can run on neutrals + one accent and stay friendly.

## 5. Existing product (tylerherman19.github.io/Coffee) - its own material
- Accent persimmon #e45f35 - the product's established identity. Kept
  (slop-review rule: sample the accent from the subject's own material).
- Fonts already loaded: Fraunces (display) + DM Sans (UI) via next/font.
  Both stay: Fraunces has real editorial character (optical sizing, tight
  tracking) and DM Sans carries tabular numerals (font-feature "tnum").
  No new font downloads, no dependency cost.
- Kill list (current tells): cream/biscuit/brown-on-beige theme, dotted
  menu-board leaders, giant 4.4rem headings, eyebrow labels on every page,
  boxed bordered toggles everywhere, centered 860px column stack, "Every
  cup on the map" style copy, noisy default OSM basemap.
